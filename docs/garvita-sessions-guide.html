The Inner Worth Wellness

How to manage your upcoming sessions

A simple guide for adding, updating, and removing sessions on your website · No technical knowledge needed

Part 1 — One-time setup

You only need to do this once. After that, you'll manage everything directly from Google Calendar.

Step A — Create a dedicated calendar

  1. Go to Google Calendar Open calendar.google.com and sign in with your Google account.
  2. Create a new calendar On the left sidebar, find Other calendars and click the + button next to it. Choose Create new calendar.
  3. Name it exactly: Inner Worth Wellness Sessions
    Click Create calendar. It will now appear in your left sidebar.
💡 Important
Events you add to this calendar show up on the website. Events in your personal calendar do not. Keep all session events in Inner Worth Wellness Sessions.

Step B — Find your Calendar ID

  1. Open Calendar Settings Hover over Inner Worth Wellness Sessions in the left sidebar. Click the three dots ⋮ that appear → choose Settings and sharing.
  2. Copy your Calendar ID Scroll down to the section called Integrate calendar. You'll see a field labelled Calendar ID. It looks something like:
    abc123xyz@group.calendar.google.com
    Copy the entire ID — you'll need it in the next step.

Step C — Set up the Apps Script

  1. Go to script.google.com Open a new tab and go to script.google.com. Click New project in the top-left.
  2. Name the project Click "Untitled project" at the top and rename it to Sessions Script.
  3. Delete everything in the editor You'll see some default text like function myFunction() {}. Select it all and delete it.
  4. Copy the script below and paste it in
    // Replace this with your Calendar ID from Step B var CALENDAR_ID = 'PASTE_CALENDAR_ID_HERE'; function doGet() { var cal = CalendarApp.getCalendarById(CALENDAR_ID); var today = new Date(); today.setHours(0, 0, 0, 0); var windowEnd = new Date(today); windowEnd.setDate(windowEnd.getDate() + 90); var sessions = cal.getEvents(today, windowEnd) .map(parseEvent) .filter(function(s) { return s !== null; }); return ContentService .createTextOutput(JSON.stringify(sessions)) .setMimeType(ContentService.MimeType.JSON); } function parseEvent(ev) { var fields = parseDescription(ev.getDescription() || ''); if (fields.hidden) return null; var start = ev.getStartTime(); var durationMin = Math.round((ev.getEndTime() - start) / 60000); var h = start.getHours(); var min = start.getMinutes(); var ampm = h >= 12 ? 'PM' : 'AM'; h = h % 12 || 12; var MONTHS = ['Jan','Feb','Mar','Apr','May','Jun', 'Jul','Aug','Sep','Oct','Nov','Dec']; return { name: ev.getTitle(), type: fields.type || 'Session', date: MONTHS[start.getMonth()] + ' ' + start.getDate() + ', ' + start.getFullYear(), time: h + ':' + (min < 10 ? '0' + min : min) + ' ' + ampm, duration: durationMin > 0 ? durationMin + ' min' : '', location: ev.getLocation() || '', spots: fields.spots || '', price: fields.price || 'Contact to book', description: fields.freeText, active: 'TRUE' }; } function parseDescription(raw) { var lines = raw.split('\n'); var sepIdx = -1; for (var i = 0; i < lines.length; i++) { if (lines[i].trim() === '---') { sepIdx = i; break; } } var freeText = (sepIdx >= 0 ? lines.slice(0, sepIdx) : lines).join('\n').trim(); var blockLines = sepIdx >= 0 ? lines.slice(sepIdx + 1) : []; var result = { freeText: freeText, hidden: false }; blockLines.forEach(function(line) { var m = line.match(/^([^:]+):\s*(.*)$/); if (!m) return; var key = m[1].trim().toLowerCase(); var val = m[2].trim(); if (key === 'type') result.type = val; if (key === 'price') result.price = val; if (key === 'spots' || key === 'spot') result.spots = val; if (key === 'hidden' && val.toLowerCase() === 'yes') result.hidden = true; }); return result; }
  5. Replace PASTE_CALENDAR_ID_HERE with your actual Calendar ID On line 2 of the script, replace the placeholder text (inside the quotes) with the Calendar ID you copied in Step B. Keep the quotes around it.
  6. Save the script Press Ctrl + S (Windows) or Cmd + S (Mac).

Step D — Deploy the script

  1. Click Deploy → New deployment The blue Deploy button is in the top-right corner of the Apps Script editor.
  2. Choose Web app as the type Click the gear icon ⚙ next to "Select type" and choose Web app.
  3. Set these two settings:
    • Execute as: Me (your Google account)
    • Who has access: Anyone
  4. Click Deploy Google will ask you to authorise the script — click through the prompts and allow access.
  5. Copy the Web App URL A long URL ending in /exec will appear. Copy it and send it to Saurabh. He'll connect it to your website.
⚠️ Important
Send the /exec URL to Saurabh. He'll paste it into the website code. This is the only time you'll need technical help. After this, everything is just creating and editing calendar events.

Part 2 — Adding a new session

Once the setup is done, this is all you ever need to do to add a session to your website.

  1. Open Google Calendar Go to calendar.google.com.
  2. Click on the date and time of your session This creates a new event. Click More options to open the full event editor (you'll need it for the description).
  3. Fill in the event details:
    • Title — the session name (e.g. Sunday Sound Bath)
    • Start and end time — set both so the duration is correct on the website
    • Location — venue name and area, or "Online · Zoom"
  4. Add the description In the Description field, write a short description of the session (optional), then on a new line add the template below. The --- line separates your description from the website fields.
Description template
A gentle evening of Tibetan singing bowls to close the week. --- type: Sound Bath price: ₹800 spots: 12
typeSound Bath, Workshop, Online, Retreat…
price₹800   or   ₹1200 per person
spots12   (or leave blank for unlimited)
  1. Make sure you're saving to the right calendar At the top of the event editor there's a calendar selector. Make sure it shows Inner Worth Wellness Sessions, not your personal calendar.
  2. Click Save — the website updates automatically No need to tell anyone or do anything else. The site checks your calendar every time someone loads the page.
💡 Featured session
The session with the soonest upcoming date automatically appears as the big featured card on your website. You don't need to do anything special — just create events and they'll order themselves.

Part 3 — Common tasks

Cancelling or removing a session

Delete the event from the Inner Worth Wellness Sessions calendar. It will disappear from the website immediately.

Hiding a session without deleting it

Add hidden: yes anywhere inside the --- block in the event description. The event stays in your calendar but won't show on the website.

Marking a session as fully booked

Edit the event and change spots: 12 to spots: 0. The website will show a grey "Fully Booked" label instead of the Book button.

Updating spots as people book

Edit the event and update the number after spots:. If you started with 12 and 3 people have booked, change it to spots: 9.

Unlimited spots (no pill shown)

Leave the spots: line out of the template entirely. The website won't show any spots indicator.

Multi-day or recurring sessions

For a multi-day retreat, create one event spanning the full date range. For weekly recurring sessions, use Google Calendar's repeat feature — each occurrence will appear on the website independently.

If the website shows no sessions

Check that you have at least one upcoming event in the Inner Worth Wellness Sessions calendar (not your personal calendar) with a start date within the next 90 days. If all your events are in the past or in a different calendar, the Sessions section hides itself automatically.

Spelling and capitalisation in the template

The script is forgiving about capitalisation — Type:, TYPE:, and type: all work. Just make sure you use a colon (:) after each key.
